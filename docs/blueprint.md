# **App Name**: FUKUROAI

## Core Features:

- Interactive 3D Mascot: Landing page with a 3D animated mascot using Spline and model-viewer.  Mascot auto-rotates with interactive camera controls, and links to other areas in the application.
- Portfolio Display: Showcase portfolio items including case studies, projects, videos, and presentations.
- Responsive Grid Layout: Landing page structured using a grid, that is fully responsive on mobile, desktop, and tablet screen sizes.
- AI-Powered Navigation: Gemini API integration for landing page navigation; an AI-powered tool guides users with questions, providing relevant links, information or project referrals.

## Style Guidelines:

- Primary color: Strong blue (#2962FF), chosen to evoke feelings of trust and stability.
- Background color: Very light blue (#F0F4FF) which helps the content stand out and makes for a gentler contrast than pure white.
- Accent color: Purple (#7928CA), used for interactive elements to catch the user's eye.
- Clean, sans-serif font for body text, prioritizing readability.
- Simple, line-based icons to maintain a modern aesthetic.
- Clean and well-organized layout with clear visual hierarchy to help the user browse.
- Subtle animations for transitions and interactions to enhance user experience without being distracting.
